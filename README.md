## How I build

- Start with an explicit product and operational contract, not a demo-only implementation.
- Prefer safe defaults: isolated data, narrow permissions, reversible actions, and no credential handling in public tools.
- Verify the full path—interface, command or API, data, and expected outcome—before calling work complete.
